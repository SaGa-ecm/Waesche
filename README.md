# Waschmittelrechner

Parametrisierte DIY-Rezeptur für selbstgemachtes Waschmittel.

## Einleitung

Dieses Tool berechnet eine maßgeschneiderte Waschmittel-Rezeptur basierend auf deinen individuellen Parametern. Einfach die Werte eingeben und die Rezeptur wird automatisch berechnet.

## Live aufrufen

Die index.html kann direkt über GitHub Pages aufgerufen werden:

**[➡️ Waschmittelrechner öffnen (index.html)](https://saga-ecm.github.io/Waesche/)**

Oder die Datei lokal im Browser öffnen: `index.html`

## Technik

- Single HTML-Datei (`index.html`), läuft komplett clientseitig im Browser
- Keine Server, keine externen Datenbanken, keine Registrierung
- Mermaid-Diagramme für Visualisierungen (via CDN)
